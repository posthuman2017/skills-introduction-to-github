# 生活介護 送迎表 自動生成 (GAS版)

Google スプレッドシート + Google Apps Script で動作する、送迎表の自動生成ツールです。

## 特徴

- インストール不要（Googleアカウントのみ）
- 利用者マスタ・車両マスタを編集して、メニューから送迎表を生成
- リフトなし車両への車椅子利用者の割当などをチェック
- 「送り」「迎え」モード切替
- 1事業所・利用者20名規模を想定

## セットアップ手順

1. Google ドライブで新しいスプレッドシートを作成
2. `拡張機能 → Apps Script` を開く
3. エディタに `Code.gs` の内容を貼り付け、ファイル名を `Code.gs` に
4. `appsscript.json` をマニフェストファイルとして編集（`プロジェクトの設定 → 「appsscript.json」マニフェスト ファイルをエディタで表示する` をオン）。中身を本リポジトリの `appsscript.json` に合わせる
5. 保存してエディタを閉じる
6. スプレッドシートを再読み込みすると、上部メニューに **「送迎表」** が表示される
7. `送迎表 → シート初期化（サンプルデータ）` を実行（初回のみ権限承認あり）

## 各シートの説明

### 設定
| 設定項目 | 値の例 | 説明 |
|---|---|---|
| モード | 送り / 迎え | 送り=自宅→事業所、迎え=事業所→自宅 |
| 出発時刻 | 08:30 | HH:mm 形式。最初の停車地の予定時刻 |
| 事業所名 | サンプル生活介護センター | 送迎表ヘッダーに表示 |
| 実施日 | 2026/04/30 | 空欄なら本日 |

### 利用者マスタ
氏名 / 住所 / 電話 / 車椅子(○ or -) / 医療的ケア(○ or -) / 備考 / 乗車所要分

`乗車所要分` = 前の利用者宅（または出発地点）からこの利用者宅までの所要分。

### 車両マスタ
車両名 / 定員 / リフト(○ or -) / 運転手 / 添乗員

### 割当（手動入力）
車両名 / 乗車順 / 氏名

ここで車両ごとの利用者と乗車順を編集してください。

## 使い方

1. 各マスタを編集
2. `割当` シートで車両ごとに乗車順と氏名を入力
3. メニュー `送迎表 → 送迎表を生成` を実行
4. `送迎表` シートに結果が出力される（印刷可）

## バリデーション

生成時に以下をチェックします:

- 割当の車両/氏名がマスタに存在するか
- 定員超過がないか
- リフトなし車両に車椅子利用者が割り当てられていないか

## 時刻計算ロジック

```
利用者1の時刻 = 出発時刻 + 利用者1.乗車所要分
利用者2の時刻 = 利用者1の時刻 + 利用者2.乗車所要分
...
```

「送り」「迎え」とも同じ計算式（基準時刻は「設定」の出発時刻）。
